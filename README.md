# newsmth-reader

极简风格的本地水木社区（NewSMTH）网页阅读器——纯单栏居中排版、电子书式无动画瞬切翻页、正文与元信息字体分层、防社死图片控制、全键盘导航与完整账号读写支持。

> 设计理念致敬开源 iOS 客户端 `Maxwin-z/xsmth-newsmth`，代码与界面基于现代 Web 技术栈从零独立实现，本地单进程运行，零云端数据收集。

---

## 核心特性

### 极简沉浸阅读
- **纯单栏居中流 + 左侧抽屉导航**：自适应桌面宽屏与移动端窄屏，正文字号与栏宽（`640 / 720 / 840px`）自由可调。
- **日间灰阶 / 深灰夜间 / OLED 纯黑 / 跟随系统**：克制无噪点的纸墨灰阶视觉体系。
- **正文与非正文彻底分层**：自定义阅读字体（系统字体 / 扫描本机字体 / 导入本地 `.ttf`、`.otf`、`.woff2`）仅作用于标题与正文；作者、时间、楼层号、引用提示保持紧凑浅灰 UI 细字，操作栏默认悬停于顶行显现，大幅提升阅读密度。
- **电子书式瞬切翻页 + 无缝自动翻页**：
  - 点击屏幕下半部分瞬间向下翻页、上半部分瞬间向上翻页，零动画延迟且严格保留至少 1 整行重复上下文；
  - 列表与帖子支持无限滚动自动预加载下一页；
  - 帖子页默认将顶栏收起为屏幕左上角极淡透明圆点，点开浮层展开完整顶栏，阅读零遮挡。
- **纯文净化 & 摸鱼控图**：默认隐藏头像与冗长昵称、自动清除各类客户端小尾巴、自动折叠长引用；图片支持三档瞬切（`纯文占位零流量` / `低饱和灰阶缩图` / `自动原图`）及原图灯箱队列。

### 高频版面友好体验
- **原生级返回位置记忆**：从列表点进帖子再按 `←` / 浏览器返回时，瞬回离开时的精确像素位置、保留已自动加载的多页与所在 Tab，不重刷不跳顶。
- **分层刷新机制**：正向进版/切 Tab 实时拉最新；按 `←` 返回超过 30 秒的列表时后台静默探测，有新帖在顶部浮出零位移胶囊提示；热帖读到最后一层后触底再点下半屏自动增量追加新回复。

### 完整账号读写与双通道登录
- **方案 B（推荐）· 本机隔离 Chrome 登录**：点击登录唤起本机独立临时 Chrome 窗口打开水木登录页，由你本人手动完成账密与滑块验证，后端通过本地 CDP 捕获会话并自动关闭窗口。
- **方案 A · 粘贴 Cookie 导入**：支持直接整段粘贴浏览器导出的 `Netscape cookies.txt`、`Cookie` 请求头、`Copy as cURL` 或 JSON 数组。
- **全功能覆盖**：今日十大、全站热帖、分区热点、全部分区、版面主题/置顶/精华/排序、版面直达搜索、全站搜帖、只看楼主/只看TA/亮评 Likes、发新帖/引用回复/编辑/删除/粘贴上传图片、Like 打分、云端版面与帖子收藏、站内私信与 `@我 / 回复 / 点赞` 提醒、本地用户与关键词屏蔽。
- 发帖/回帖/Like 触发风控校验时，直接挂载水木官方极验 4（Geetest v4）弹窗由用户本人手动验证，**不提供任何绕过验证码的功能**。

## 快速开始

需要 **Node.js `>= 22`**（支持 macOS / Windows / Linux）。

```bash
# 1. 克隆仓库并进入目录
git clone https://github.com/dvbs2000/newsmth-reader.git
cd newsmth-reader

# 2. 安装依赖
npm install

# 3. 构建前后端
npm run build

# 4. 启动本地单进程服务（默认 http://127.0.0.1:3173）
npm start
```

打开浏览器访问 `http://127.0.0.1:3173` 即可游客态浏览，或点左上角菜单登录后开启完整读写与云端同步。

### 常用命令与环境变量
- `npm run dev`：开发模式（前端 `127.0.0.1:3173` + BFF `127.0.0.1:3174` 热重载）
- `npm run typecheck`：前后端严格 TypeScript 类型检查
- `npm test`：运行单元测试与 BFF 集成测试
- `PORT=8080 npm start`：自定义监听端口
- `SMTH_CHROME_PATH=/path/to/chrome`：自定义方案 B 使用的本机浏览器可执行文件路径

## 键盘快捷键

| 按键 | 功能 |
|---|---|
| `/` | 打开全局版面直达与全站搜索面板 |
| `←` / `→` | 返回上一级页面（保留精确位置） / 前进到刚才离开的页面 |
| `J` / `K` | 在列表或楼层间向下 / 向上移动焦点 |
| `Enter` | 打开当前聚焦的帖子 |
| `Esc` | 关闭弹窗或抽屉，或返回上一级 |
| `U` | 立即刷新当前列表或帖子并归顶（再点当前 Tab 也可刷新） |
| `O` | 帖子内切换「只看楼主 / 全部楼层」 |
| `R` | 帖子内快速回复（不冲突 `Ctrl+R` / `Cmd+R` 浏览器刷新） |
| `N` | 版面内快速发表新帖 |
| `D` | 循环切换主题（日间灰阶 → 深灰夜间 → OLED 纯黑） |
| `I` | 循环切换图片控图（纯文占位 → 灰阶缩图 → 自动原图） |
| `?` | 打开 / 关闭快捷键说明面板 |

## 隐私与安全说明

- **100% 本地单机运行**：你的登录 Cookie、个人偏好、屏蔽名单、已读记录和本地导入的字体文件全部保存在项目 `.local/` 目录（会话文件权限 `0600`，且已被 `.gitignore` 忽略），不会上传到任何第三方服务器。
- **图片代理 SSRF 防护**：本地 `/api/proxy/image` 仅放行水木及相关图片 CDN 域名白名单，拦截内网地址与非允许域名。
- **严控 XSS**：所有上游正文先剥离不安全标签并结构化解析为纯文本、引用块、链接和图片列表，不直接注入原始 HTML。
- **不含商业字体**：仓库不内置任何商业版权字体；如需使用个人合法拥有的 `.ttf` / `.otf` / `.woff2` 字体，可在「偏好设置 → 字体与排版」直接导入至本机 `.local/fonts/`。
